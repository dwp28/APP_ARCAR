# Recursos del prototipo

SVG originales exportados de las 16 pantallas del archivo de Figma `OOlI7kOF5jODjBgmeMvH13` de App Arcar. Los nombres contienen los primeros 20 caracteres del SHA-256 del recurso para reutilizar un único archivo cuando varias pantallas usan el mismo contenido.

El inventario de pantallas y el uso de los recursos se documentan en [prototipo-web.md](../../docs/prototipo-web.md). Las referencias estáticas se encuentran en `src/prototype/generated/`. No se utilizan capturas de pantalla completas como elementos de interfaz.
