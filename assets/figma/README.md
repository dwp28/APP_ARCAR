# Recursos de App Arcar

Iconos y vectores exportados del archivo de diseño del equipo el 24/11/2026. Los recursos se incluyen localmente y no dependen de enlaces temporales de Figma.

Fuente: https://www.figma.com/design/OOlI7kOF5jODjBgmeMvH13?node-id=68-2291

Los vectores cartográficos de referencia proceden de los datos de OpenStreetMap: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright. El mapa nativo usa el proveedor de cada plataforma; la vista web es un esquema del catálogo de demostración.

La fuente Inter se distribuye a través de @expo-google-fonts/inter y conserva su licencia SIL Open Font License en ese paquete.
